# Cal.com references and operating notes

Documentation checked 2026-09-23. Inspect the current interface and the account's feature availability instead of relying on fixed screen coordinates or old screenshots.

[Event types guide](https://cal.com/blog/event-types-guide-calcom): personal links serve individual hosts; managed types distribute standard settings to selected teammates; collective types require multiple hosts; round robin distributes meetings among hosts. Create/select the event type, configure its details, assign hosts where relevant, then attach availability. Team capabilities depend on the account.

[Date overrides](https://cal.com/blog/what-are-date-overrides-and-how-do-i-enable-them): open Availability, select the schedule, add date-specific hours or unavailable days, and save. Overrides affect event types using that schedule. Use a dedicated conference schedule to avoid unintentionally changing unrelated links. Verify the event's date range separately.

[Minimum notice](https://cal.com/blog/setting-up-minimum-notice-period-in-scheduling): configure the notice interval under the event type's Limits controls. This limits how soon someone can book; it is separate from the buffer around an appointment.

[Calendar settings overview](https://next.cal.com/atoms): calendar configuration includes selecting calendars to check for conflicts. A connected calendar account and a booking destination are not substitutes for verifying that selection for each host.

[Troubleshooting feature](https://cal.com/blog/learn-all-about-cal-com-s-troubleshooting-feature): use the diagnostic view to investigate availability restrictions from schedules, connected calendars and booking limits. Verify the resulting public page after a correction.

Operational lessons: an unanswered all-day conference invitation can still be Busy; a template can be correct while one host's calendar suppresses every slot; a buffer does not necessarily create an equally spaced booking grid; date boundaries must be tested in the venue and visitor timezones. These are diagnostic possibilities, not instructions to weaken conflict checking.
